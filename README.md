# GarageHub — API de Gestão de Oficinas Automóveis

O GarageHub é um projeto backend desenvolvido para gerir as operações diárias de uma oficina automóvel. Disponibiliza uma API RESTful para a gestão de clientes, veículos, funcionários, ordens de reparação, fornecedores e peças.

O projeto centra-se no desenvolvimento backend, na conceção de bases de dados relacionais, na arquitetura de APIs, na validação de dados e na implementação de regras de negócio.

## Funcionalidades

- **Gestão de Clientes** — Criar, consultar, atualizar e eliminar registos de clientes.
- **Gestão de Veículos** — Gerir veículos associados aos respetivos clientes.
- **Gestão de Funcionários** — Gerir registos de funcionários e as respetivas contas de utilizador.
- **Gestão de Ordens de Reparação** — Criar e gerir ordens de reparação, incluindo os seus estados e datas de conclusão.
- **Gestão de Inventário** — Gerir peças, fornecedores e quantidades em stock.
- **Pesquisa Avançada** — Filtrar registos com base em múltiplos critérios.
- **Autenticação** — Implementação de autenticação baseada em JWT e controlo de acessos por perfil em desenvolvimento.
